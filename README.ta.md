# ResceneAgent

> முனைநிலைக்கு (frontend) சிறப்புரிமை பெற்ற பல-முக agent தளம் —— ஒரு IDE, முனையம் (terminal), உலாவி மற்றும் ஒரு AI குழுவை ஒரே உரையாடல் பெட்டிக்குள் அடக்குகிறது. டிஜிட்டல் ஆளுமை 「Rescene」 ஐ மையமாகக் கொண்டு, தேவைப் பகுப்பாய்வு → குறியீடு → இயக்க நேரச் சரிபார்ப்பு வரை உள்ள வட்டத்தை ஒரே உரையாடலிலேயே முடிக்கிறது.

（தமிழ் பதிப்பு மொழிபெயர்க்கப்பட உள்ளது. தற்போது சீன (எளிய) README.md ஐ உதாரணமாகக் கொள்க. மொழிபெயர்ப்பில் பங்களிக்க அழைக்கிறோம்.）
