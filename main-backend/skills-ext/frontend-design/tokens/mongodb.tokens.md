# Design: Mongodb
# Type: dark

> MongoDB's website is a deep-forest-meets-terminal experience — a design system rooted in the darkest teal-black (`#001e2b`) that evokes both the density of a database and the depth of a forest canopy.

  Action Blue: #006cfa
  Hover Blue: #3860be

  Deep Teal: #1c2d38
  Teal Gray: #3d4f58
  Dark Slate: #21313c
  Cool Gray: #5c6c75
  Silver Teal: #b8c4c2
  Light Input: #e8edeb

--- Components ---
  · Primary Green (Dark Surface)
  · Dark Teal Button
  · Outlined Button (Light Surface)
  · Neon Green Accent Underlines
  · Source Code Label System
